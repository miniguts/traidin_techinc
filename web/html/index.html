🐳 Docker · Nginx · Flask · Redis

Веб-сайт в Docker

Собственный HTML/CSS-сайт, который отдаёт Nginx из Docker-контейнера. Рядом работают API на Flask и база Redis — всё поднимается одной командой docker compose up.

— посещений (хранится в Redis)
— APP_ENV из файла .env
— hostname контейнера API

Архитектура

Браузер localhost:8080
→ports
web nginx:alpine сеть frontend
→/api/
api python:3.12 + Flask frontend + backend
→6379
redis redis:7-alpine сеть backend · volume

Что используется

📦 Контейнеры

Три сервиса: web, api, redis.

📝 Dockerfile

Собственные образы для Nginx-сайта и для API.

🧩 Docker Compose

Один файл docker-compose.yml описывает весь стек.

🌐 Network

frontend и изолированная backend (internal).

💾 Volume

redis_data — данные, web_logs — логи Nginx.

🔌 Порты

Наружу проброшен только Nginx: ${WEB_PORT}:80.

⚙️ .env

Порты, пароль Redis, режим и заголовок сайта.

Гостевая книга

Сообщения сохраняются в Redis на Docker Volume — они переживут docker compose down и повторный запуск.
